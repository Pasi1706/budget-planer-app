## 🚀 Features

*   **Income & Expense Tracking:** Easily log daily financial activities.
*   **Budgeting Goals:** Set monthly or weekly limits to avoid overspending.
*   **Visual Analytics:** Clear charts and summaries of your spending patterns.
*   **Transaction History:** A detailed history log of all past transactions.
